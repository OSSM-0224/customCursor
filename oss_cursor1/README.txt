FLOATING T-SHIRT CURSOR — VERSION 2

1. Extract this ZIP.
2. Open the folder in VS Code.
3. Run index.html with the Live Server extension.
4. Move the mouse to test the cursor.

Files:
- index.html: demo page
- style.css: cursor size, positioning and layers
- cursor.js: smooth following and independent sleeve sway
- shirt-body.png: torso layer
- sleeve-left.png: left sleeve layer
- sleeve-right.png: right sleeve layer
- shirt-original.png: original reference

To use on your own website:
- Copy the three PNG layer files into your site's public/assets folder.
- Add the three image elements from index.html inside your page.
- Copy the CSS rules and JavaScript into your project.
- Update the image src paths if your asset folder differs.

Note: This is a 2D layered animation, not a true cloth physics simulation.
